Normalization Methodology

1NF

First Normal Form

Eliminate repeating groups and ensure atomic values

  • Split Specifications1-50 into separate table
  • Remove multi-valued fields
  • Ensure unique primary keys
2NF

Second Normal Form

Remove partial dependencies on composite keys

  • Separate user data from time tracking
  • Create proper foreign key relationships
  • Remove partial dependencies
3NF

Third Normal Form

Eliminate transitive dependencies

  • Separate customer data from contracts
  • Create lookup tables
  • Remove transitive dependencies
