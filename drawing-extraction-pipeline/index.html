The Challenge

Unlocking Hidden Data from Legacy Engineering Drawings

Vast amounts of valuable part information were locked in legacy engineering drawings, making it difficult and time-consuming to access, search, or analyze. Manual extraction was impossible at this scale—automation was the only viable solution.

The Solution

Step-by-step technical implementation process

1

Batch Conversion

Converted ~20,000 engineering drawings (DWGs) to PDFs using DocuFreezer for standardized processing

DocuFreezer
2

Model Training

Labeled 300+ drawings using Label Studio and fine-tuned YOLO V8M model for precise table detection

YOLO V8M Label Studio
3

Automated Detection

Ran trained model on all PDFs to generate JSON files with precise bounding box coordinates

Python Computer Vision
4

Data Extraction

Developed Python pipeline using coordinates to extract table and metadata content from each drawing

Python PDF Libraries
5

Data Consolidation

Consolidated all part data into master Excel file with drawing numbers, SKUs, serials, and customer info

Python Excel Processing
